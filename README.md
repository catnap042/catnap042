### Hi, I'm catnap042

I build small open-source tools for battery data analysis and research figures, in my spare time.

#### Projects

**[ocvfit](https://github.com/catnap042/ocvfit)**: fit a cell's open-circuit-voltage curve to electrode potentials and split capacity fade into degradation modes (loss of lithium inventory, loss of active material). Works as a Python package, CLI, MCP server and agent Skill.

**[research-plot-skill](https://github.com/catnap042/research-plot-skill)**: an agent Skill and matplotlib style for clean, consistent research data figures (capacity fade, dQ/dV, XRD and more), with paper and talk presets.

#### Data policy

Every example in these repos uses public literature data or synthetic data only.
